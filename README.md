## ✨ What is Katha?

Katha isn't just another entertainment tracker. It's a **personal memory engine** that transforms your entertainment journey into wisdom, insights, and legacy. Every movie, series, anime, documentary, and book you experience becomes a permanent chapter of your life story.

Built with an ultra-premium **glassmorphic aesthetic** inspired by the intersection of Apple's polished UI and Netflix's dark, immersive cinematic experience.

<br/>

## 🌟 The Katha Experience

### 🧠 Smriti Intelligence
At the core of Katha is **Smriti** — a local AI engine that learns from your consumption. It tracks your emotional resonance, extracts life lessons from your favorite stories, and maps your personal growth over time. 

### 📚 The Universal Library
A unified digital bookshelf with smart categorization for everything you consume. No more jumping between IMDb, MAL, and Goodreads. Movies, anime, TV shows, and books — all live here.

### 🧭 The Smriti Atlas (Discover)
A curated discovery engine that kills decision fatigue. It recommends stories based on your *current mood*, your *life phase*, and deep *editorial collections*.

### 🔮 Memory World
Step into four unique realms: 
- **The Timeline**: A chronological journey of your media life.
- **The Gallery**: A visual mosaic of everything you've watched.
- **Emotional Map**: See how different stories made you feel over the years.
- **Life Journal**: The wisdom and quotes you've extracted.

<br/>

## 🔒 100% Privacy. Zero Cloud.

We believe your stories are intimately yours. Katha is a **Local-First PWA (Progressive Web App)**.
* **No Servers:** Your data never leaves your device.
* **Offline First:** Works flawlessly on an airplane or in a cabin in the woods.
* **Your Data:** Export everything instantly to JSON, PDF, or Word.

<br/>

## 🎨 The Midnight Library Design System

Katha features a custom, premium design system built on top of Tailwind CSS and Framer Motion.

* **Canvas:** Deep midnight black `(#04050C)`
* **Surfaces:** Translucent glassmorphism with dynamic ambient glow.
* **Neon Accents:** 
  * 🟣 **Violet** (Wisdom & Intelligence)
  * 🔵 **Cyan** (Memory & Discovery)
  * 🔴 **Rose** (Emotion & Heart)
  * 🟢 **Emerald** (Growth & Action)
* **Motion:** Magnetic cursors, staggered blur reveals, fluid spring animations, and text-reveal effects.

## 🚀 Quick Start

Ready to build your personal atlas?

```bash
# 1. Clone the repository
git clone https://github.com/AdityaPatil2549/Katha.git
cd Katha

# 2. Install dependencies
npm install

# 3. Set up your environment variables
# Copy .env.example to .env.local and add your API keys
cp .env.example .env.local

# 4. Start the development server
npm run dev
```

Visit `http://localhost:5173` (or `3003`) to enter the Katha universe.
